## Forcythe Landing Page Challenge.

This app was built with React and vite. Tailwindcss was used for styling.

[Demo](https://forcythe-tim.vercel.app)

### Run app locally, ensure nodejs is install

clone the repository [https://github.com/Timmyojo/forcythe.git](https://github.com/Timmyojo/forcythe.git)

cd the the project directory

Run npm install and npm run dev
